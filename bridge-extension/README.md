# IELTS 写作批改桥

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `listening-cloze/bridge-extension`。
5. 打开并登录 `https://chatgpt.com/`，保留一个正常对话标签页在前台或可见状态。
6. 通过项目里的 `启动练习.cmd` 打开练习网页。

扩展只读取本机 `127.0.0.1:8765` 的待批改任务，只在 ChatGPT 页面填写批改提示并读取本次新回复。登录、验证码、账号授权仍由用户本人完成。
