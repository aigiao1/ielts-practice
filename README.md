# IELTS 练习中心

本地练习中心包含两个大类：王陆语境听写，以及写作翻译练习。写作大类下分为 Task 1（1–140）和 Task 2（121–240），默认每次显示一个完整的5题题组，也可以连续批改10题。

## 启动

双击 `启动练习.cmd`。脚本会在后台启动本机服务，并用默认浏览器打开 `http://127.0.0.1:8765/`。双击 `停止练习服务.cmd` 可以停止该后台服务。

## 写作翻译练习

1. 在顶部选择“写作翻译练习”，再选择 Task 1 或 Task 2。
2. 每次填写5题或10题后，只按一次“批量提交”。
3. 页面立即显示每道题的标准答案，并记录已经完成的题组。
4. 如果已经安装批改桥扩展，整批答案会自动交给已登录的 ChatGPT 页面；回复完成后，错误、最小修改版、自然表达和建议会分别显示在对应题目下方。

写作进度和王陆听写进度分别保存在浏览器本机。ChatGPT 自动批改失败不会影响标准答案或做题进度。

### 安装 ChatGPT 网页批改桥

1. 在 Chrome 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录下的 `bridge-extension` 文件夹。
4. 打开并登录 `https://chatgpt.com/`，保持一个正常对话标签页开启。
5. 回到练习页批量提交5题或10题。

扩展不会读取浏览器 Cookie、密码或账号存储；它只从本机服务领取待批改文本，在 ChatGPT 输入框中发送，并把本次新回复送回练习页。登录、验证码和账号授权必须由用户本人完成。ChatGPT 页面结构变化时，自动批改可能暂时失效，但本地练习仍可正常使用。

### 用手机练习

1. 让手机与电脑连接同一个 Wi-Fi。
2. 双击 `手机同网练习.cmd`。
3. 按窗口显示的地址，在手机的 Safari、Edge 或 Chrome 中打开。
4. 练习期间保持该窗口开启；首次出现防火墙提示时只允许“专用网络”。

电脑关机、退出脚本或手机离开同一 Wi-Fi 后，手机页面将无法访问。电脑端和手机端的浏览器进度彼此独立，可通过设置里的“导出/导入学习进度”转移。

如果电脑端隐藏服务已经占用8765端口，请先双击 `停止练习服务.cmd`，再启动手机同网练习。手机提交写作批改时，电脑端仍需保持Chrome和已登录的ChatGPT标签页开启。

## 建议练法

1. 不看中文，播放完整句子两次。
2. 输入缺失词或词组并提交。
3. 看完答案后，在答案下方的拼写框里再亲手默写一遍。
4. 最后只需标记“认识”或“不认识”；程序不再自动安排复习日期。
5. 学新词时选择“学习新词”，想重新背生词时选择“重背生词”。
6. 遇到不自然或含义不合适的自动句，点击“句子有问题”，后续可根据记录集中修改。

默认情况下，每次进入下一题都会自动朗读完整句子；可以在右上角设置中关闭。

全程可以使用键盘：答案框按 `Enter` 提交，提交后自动聚焦二次拼写框；拼对后再次按 `Enter` 接受推荐标记并进入下一题。还没提交时，按 `1` 等于交白卷，会记错并显示答案；按 `2` 会直接标记为“认识”并跳到下一题。答案显示后，按 `1` 标记“不认识”，按 `2` 标记“认识”。`1/2` 不会写进输入框，随时按 `F2` 可以重听完整句子。

提交答案或点击“不会，显示答案”后，页面会自动展开完整中文译文，并在英文完整句和中文提示区中突出显示本题目标词。目前 Ch3.2–Ch3.9 的 1,023 条精修句均带本地译文，打开和练习时不需要联网。

## 数据与隐私

- 题库来自项目根目录的 `雅思王 雅思 听力 语料库.csv`。
- 学习进度保存在浏览器本机，不上传到任何平台。
- 只有点击写作“批量提交”后，该批中文、用户答案和标准答案才会发送到已登录的 ChatGPT 页面用于批改。
- 设置中可以导出和导入进度 JSON，建议每天备份一次。
- 重新生成题库：在本目录执行 `node scripts/build-data.mjs`。
- 重新生成写作题库：在本目录执行 `node scripts/build-writing-data.mjs`。
